# Stock-Trade-App
A comprehensive stock trading application built with the MERN stack (MongoDB, Express.js, React, Node.js). This application allows users to register, login, view stock prices, buy/sell stocks, and track their portfolio.

## Features

- **User Authentication**: Secure user registration and login system.
- **Dashboard**: Real-time stock market data and portfolio overview.
- **Stock Market**: Browse and search for stocks with their current prices.
- **Buy & Sell**: Execute trades to buy or sell stocks.
- **Portfolio Management**: Track owned stocks, quantities, and total value.
- **Transaction History**: View complete history of buy and sell transactions.
- **Admin Panel**: Manage stocks (add, update, delete).

## Tech Stack

### Frontend
- **React**: JavaScript library for building the user interface.
- **CSS**: Styling for the application.

### Backend
- **Node.js**: JavaScript runtime for the server.
- **Express.js**: Web framework for building the API.
- **MongoDB**: NoSQL database for storing user data and stock information.
